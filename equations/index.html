Quantité de matière

  • Massen en mol, m en g, M masse molaire en g·mol−1
    n = m / M
  • Nombre d’entitésNA = 6,022 × 1023 mol−1
    n = N / NA
  • GazVm ≈ 24 L·mol−1 à 20 °C et 1 atm
    n = V / Vm
  • Masse volumique, densitéρeau = 1,00 g·mL−1
    ρ = m/V ; d = ρ / ρeau

Solutions

  • Concentration molaireen mol·L−1
    C = n / V
  • Concentration massiqueen g·L−1
    Cm = m / V = CM
  • Dilutionla quantité de soluté se conserve ; facteur de dilution F = Ci/Cf
    CiVi = CfVf
  • Fraction massique
    w = msoluté / msolution

Gaz parfaits

  • Équation d’étatR = 8,314 J·K−1·mol−1 ; P en Pa, V en m3, T en K
    PV = nRT
  • Température
    T (K) = θ (°C) + 273,15
  • Pression partielle (Dalton)xi : fraction molaire
    P = Σ Pi ; Pi = xiP

Réaction chimique

  • Tableau d’avancementνi < 0 pour un réactif, > 0 pour un produit
    ni = ni,0 + νix
  • Réactif limitant
    xmax = min(ni,0 / |νi|)
  • Rendementou mexp / mmax
    η = nexp / nmax

Acides et bases

  • pHconcentration en mol·L−1
    pH = −log [H3O+] ; [H3O+] = 10−pH
  • Produit ionique de l’eauà 25 °C ; pH + pOH = 14
    Ke = [H3O+][HO−] = 10−14
  • Constante d’acidité
    Ka = [H3O+][A−] / [HA] ; pKa = −log Ka
  • Relation de HendersonpH = pKa quand [A−] = [HA]
    pH = pKa + log([A−]/[HA])
  • Acide fort, base fortesolutions diluées
    pH = −log C ; pH = 14 + log C
  • Acide faiblesi l’acide est peu dissocié
    pH = ½(pKa − log C)
  • Dosageà l’équivalence, pour une stœchiométrie 1 : 1
    CAVA = CBVB

Énergie des réactions

  • Quantité de chaleurc capacité thermique massique ; eau : 4,18 J·g−1·K−1
    Q = mcΔT
  • Loi de Hess
    ΔrH° = Σ ν ΔfH°(produits) − Σ ν ΔfH°(réactifs)
  • Enthalpie libreréaction spontanée si ΔG < 0
    ΔG = ΔH − TΔS
  • Constante d’équilibre
    ΔG° = −RT ln K
  • Quotient de réaction
    ΔG = ΔG° + RT ln Q

Cinétique

  • Vitesse de réactionν : nombre stœchiométrique en valeur absolue
    v = (1/ν) d[X]/dt
  • Ordre 0
    [A] = [A]0 − kt ; t1/2 = [A]0 / 2k
  • Ordre 1ln[A] est une droite en fonction de t
    [A] = [A]0e−kt ; t1/2 = ln 2 / k
  • Ordre 2
    1/[A] = 1/[A]0 + kt
  • Loi d’Arrheniusln k = ln A − Ea/RT
    k = Ae−Ea/RT

Équilibre chimique

  • Constante d’équilibrepour aA + bB ⇌ cC + dD, concentrations à l’équilibre
    K = [C]c[D]d / ([A]a[B]b)
  • Sens d’évolution
    Q < K : sens direct ; Q > K : sens inverse
  • Van ’t Hoffexothermique : K diminue quand T augmente
    d ln K / dT = ΔH° / (RT2)
  • Produit de solubilitéexemple : AgCl, s = √Ks
    Ks = [Ag+][Cl−]

Oxydoréduction, piles

  • Formule de Nernstà 25 °C ; général : E° + (RT/nF) ln([Ox]/[Red])
    E = E° + (0,059 / n) log([Ox]/[Red])
  • Force électromotricela cathode est le pôle +
    E = Ecathode − Eanode
  • Enthalpie libre et potentielF = 96 485 C·mol−1
    ΔG° = −nFE°
  • Électrolyse (Faraday)n : électrons échangés
    m = MIt / (nF)
  • Quantité d’électricité
    Q = It = neF

Atome et spectroscopie

  • Nombres quantiquesune couche n contient au plus 2n2 électrons
    n ≥ 1 ; 0 ≤ ℓ ≤ n−1 ; −ℓ ≤ mℓ ≤ ℓ ; ms = ±½
  • Niveaux de l’hydrogène1 eV = 1,602 × 10−19 J
    En = −13,6 eV / n2
  • Photonh = 6,626 × 10−34 J·s ; c = 2,998 × 108 m·s−1
    E = hν = hc/λ
  • Loi de Beer–LambertA = log(I0/I) ; ℓ : épaisseur de la cuve
    A = ε ℓ C

Thermodynamique chimique (prépa)

  • Potentiel chimique, activitégaz parfait : ai = Pi/P° ; soluté : ai = [i]/C° ; solide et solvant : ai = 1
    μi = μi° + RT ln ai
  • Enthalpie libre de réactionà l’équilibre : ΔrG = 0 et Qr = K°
    ΔrG = ΔrG° + RT ln Qr ; ΔrG° = −RT ln K°
  • Évolution d’un système
    Qr < K° : sens direct ; Qr > K° : sens inverse
  • Gibbs–Helmholtz, Ellinghamapproximation d’Ellingham : ΔrH° et ΔrS° indépendants de T
    ΔrG° = ΔrH° − TΔrS°
  • Loi de Kirchhoff
    ΔrH°(T2) = ΔrH°(T1) + ∫T1T2 ΔrCp° dT
  • Loi de Van’t Hoffintégrée : ln(K2/K1) = −(ΔrH°/R)(1/T2 − 1/T1)
    d ln K° / dT = ΔrH° / (RT2)
  • Variance (règle des phases)N constituants, r équilibres, k relations supplémentaires, φ phases
    v = N − r − k + 2 − φ
  • Lois de Raoult et de Henrymélange idéal ; soluté dilué
    Pi = xiPi* ; Pi = kHxi
  • Théorème des moments chimiquespoint M dans le fuseau d’un diagramme binaire, L et V sur l’horizontale passant par M
    nliq × ML = nvap × MV

Solutions aqueuses (prépa)

  • Condition de précipitationdébut de précipitation : Q = Ks
    précipite si Q = Π [i]νi > Ks
  • Complexationconstante globale de formation de M + nL ⇌ MLn
    βn = [MLn] / ([M][L]n)
  • Domaines de prédominance
    pH > pKa : base prédominante ; pH < pKa : acide prédominant
  • Demi-équivalence d’un dosageacide faible dosé par une base forte
    pH = pKa
  • Conductivité de la solutionλi : conductivité molaire ionique ; σ en S·m−1
    σ = Σ λi[Xi]
  • Force ioniquezi : charge de l’ion i
    I = ½ Σ cizi2
  • Constante d’équilibre d’une réaction redox25 °C ; l’oxydant du couple 1 réagit avec le réducteur du couple 2
    log K° = n(E°1 − E°2) / 0,059
  • Charge d’une pileQ en coulombs
    Q = nF ; Q = It

Cinétique (prépa)

  • Loi de vitesseordres partiels α et β ; ordre global α + β
    v = k[A]α[B]β
  • Temps de demi-réaction
    ordre 0 : [A]0/2k ; ordre 1 : ln 2/k ; ordre 2 : 1/(k[A]0)
  • Quasi-stationnaritéAEQS : intermédiaire réactionnel très réactif
    d[I]/dt ≈ 0
  • Énergie d’activation
    ln(k2/k1) = −(Ea/R)(1/T2 − 1/T1)
  • Substitution et éliminationNu : nucléophile ou base
    SN1 et E1 : v = k[RX] ; SN2 et E2 : v = k[RX][Nu]
  • Stéréoisomèrespour n centres stéréogènes ; moins en présence de symétrie (composés méso)
    au plus 2n stéréoisomères
